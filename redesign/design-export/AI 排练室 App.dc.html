改版思路
1 · 样式 按需求文档“像一本干净的工作手册”：暖白纸色 + 墨黑 + 一个朱红点缀。标题用宋体，正文 ≥17px。功能图标用单个汉字（读 / 职 / 传 / 访 / 网），不再用彩色书封。
2 · 结构跟着她的工作走 保留“一本书 = 一个功能”的书架，左右滑动换书，中间那本放大；书下方只显示这本的用途和一个“翻开这本”按钮。书封用统一的版式（阶段 · 图标 · 书名），颜色同明度不同色相。第一本是最有“哇”感的做网页。收藏和话术卡放进底部标签栏。
3 · 五个功能，一套操作 每个功能页结构相同：一句说明 → 你会得到 + 预填例子 → “直接试试 / 换我来说” → 对话 → 结果卡。底部永远是同一个“按住说话”大按钮，左侧最多一个辅助键（拍一句 / 跳过 / 再问一遍）。结果出来后底栏统一变成“再来一次 / 收藏”。
前提假设 称呼暂用“一桐”。Figma 链接我打不开，样式没参考原稿。台词、记者问题、角色描述都是示意，需要团队核对。
