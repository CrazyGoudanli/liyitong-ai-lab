# 改版设计稿（redesign 分支）

这个分支只放改版设计稿，不改线上版的 `app.html` / `server.js`。

来源：Claude Design 导出的原型 `design-export/AI 排练室 App.dc.html`，和用户一起迭代的过程记录在 `design-export/chat.md`。

## 怎么看

直接用手机或电脑浏览器打开 `redesign/index.html`（双击即可，不需要服务器）。电脑上会居中显示成 390px 宽的手机版面。

可以带 `#job #bio #line #press #web` 直接打开某一本书。

## 和原型一致的部分

- 样式：暖白纸色 `#F5F3EE` + 墨黑 `#1D1C1A` + 朱红 `#B8432B`，标题用宋体，正文 ≥17px
- 首页：一排书，左右滑，中间那本放大。从左到右依次是职业功课、人物小传（进组前）→ 台词速懂（拍戏期）→ 采访陪练（宣传期）→ 一句话做网页（个人表达）。点中间的书或“翻开这本”进入，点旁边的书会把它滑到中间
- 书的封面用当前这部戏的海报，叠一层这本书的颜色，封面中间不放大字
- 右上角下拉选戏：切换、新增、管理（删除、传海报）
- 五个功能同一套操作：一句说明 → 你会得到 + 填好的例子 → “直接试试 / 换我来说” → 对话 → 结果卡。底部永远是“按住 说话”，左边最多一个辅助键（拍一句 / 跳过 / 再问一遍）。结果出来后底栏变成“再来一次 / 收藏”
- 底部标签栏：体验 / 我的收藏 / 话术卡

## 和原型不同的地方

- 去掉了手机外框、假状态栏和右侧“改版思路”说明。改成全屏手机页，顶部和底部留出了刘海和底部横条的安全距离
- 去掉了原型里的“首页布局：书架 / 网格”切换开关，只保留书架
- 不加载 Google Fonts，国内打不开。宋体用手机自带的（iPhone 上是宋体-简）
- 收藏和戏单存在手机本地（`localStorage`，前缀 `ytlab.v2.`，和线上版的 `ytlab.` 分开），刷新后还在。上传的海报会先缩到 640px 宽再存
- 海报压缩成了 JPG（`posters/`，约 80KB / 130KB），原图 3–4MB
- 收藏列表的时间按真实时间显示（刚刚 / 今天 14:05 / 昨天 / 10月21日），还加了一个空状态的提示
- “职业功课”里 AI 的称呼跟着当前戏的职业变（原型里固定是“AI 律师”）
- 支持手机的返回手势和返回键：在功能页里返回，会回到首页

## 接豆包（火山方舟）

“我的收藏”右上角“设置”→ 填 API Key → “保存并测试”。之后五本书都用豆包真的回答，没填就是演示脚本。

- 网页直接从手机调用火山方舟，密钥只存在这台手机的浏览器里（`ytlab.v2.ark`），**不要写进仓库**（仓库是公开的）
- 请求里带 `thinking: {type: "disabled"}`，关掉深度思考，出字更快
- 默认模型 `doubao-seed-2-1-pro-260915`，可以在设置里改成别的模型或接入点
- “直接试试”：她那一侧用示例里的话，AI 那一侧是豆包现场回答；“换我来说”：底栏变成输入框，可以打字或用键盘上的麦克风说
- 台词速懂在“换我来说”里点“拍一句”可以拍照，图片会发给豆包看（模型要支持图片）
- 一句话做网页：豆包现场写一个网页放在预览框里，可以接着说怎么改
- AI 出错时会提示原因，并自动换回示例内容，不会卡住
- 火山方舟是否允许网页直接调用（跨域）需要在手机上实测；设置里“保存并测试”会告诉你结果

## 每部戏的示意内容

`index.html` 里的 `PACKS` 按剧名放了两部戏的示意内容（职业功课、人物小传、采访陪练、台词速懂），`brief` 是公开报道里的剧情简介，也会发给豆包当背景。

- 《美人余》余梦：江浙富家独生女，结婚五周年发现丈夫狄立人和保姆卢蕙设局“吃绝户”，找律师查流水、收聊天记录、盯房产股权变更，冷静反击。职业功课里 AI 扮婚姻家事律师
- 《我不是大师》江飞燕：表面是戏班花旦，实为骗术组织“天相派”的卧底，精通易容和读心；大婚之夜身份被揭穿，和上官诚明从互相试探到联手瓦解天相派。职业功课里 AI 扮民国戏班花旦

剧情只来自网上的公开报道（新浪、微博、电视猫等转载），部分细节各家说法不一，**以剧方官方信息为准**。

## 还没做（这一版是设计稿）

- 没填密钥时，对话和结果是写死的演示脚本。“按住说话”还没接真正的语音识别，松开后发出的是写好的那句话
- 自己新增的戏只有通用示意内容，连上 AI 后才会按这部戏来
- 示意台词、对话、记者问题都是写的，不是剧中原句，需要团队核对
- 定下来以后，再把这套样式和交互合进 `app.html`，接上现有的 AI 接入、朗读和说话输入
